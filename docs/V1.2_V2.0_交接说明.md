## 6. 硬约束（违反即返工）

1. **C1 权威口径唯一**：任何"已选人数"的对外展示与统计 = DB `COUNT(course_selection WHERE status='SELECTED')`。Redis 计数 Key 与 `teaching_class.selected_count` **只是并发互斥器，统计严禁读**。
2. **C8 跨学期累计**：S-02 / I-01 禁止复用 `CreditServiceImpl`、`ScoreMapper#listPublishedScoreByStudent`、`buildCourseMapOfSelection`（均带 `semester_id` 过滤）。只能用 `ScoreMapper#listPublishedScoreByStudentId` + `CourseSelectionMapper#listSelectionByStudentId`。**不要改 V1.1 的 `GET /student/credits`**。
3. **冻结文件（禁止修改，只能末尾追加开关）**：9 个已有 Mapper（`CourseSelection` / `TeachingClass` / `TeachingClassSchedule` / `Score` / `SelectionBatch` / `Student` / `Classroom` / `Course` / `Teacher`）、`RedisCommonConstant`、`RedisKeyUtil`、`ResultCodeEnum`、`application*.yml`、`docs/接口文档.md`（T9 独占）。
4. **MyBatis-Plus**：Mapper 继承 `BaseMapper<DO>`，对外只暴露 `get/list/count/save/update/remove` 前缀的 `default` 方法；分页走 `Page.of` + `PaginationInnerInterceptor`，不手写 LIMIT；**不新增 XML**；Wrapper 里枚举字段传枚举实例，字符串转枚举用 `EnumParseUtil.parseOrNull`。
5. **命名**：入参 `requestParam`，返回值 `result`，循环 `each`，Map 遍历 `entry`，捕获异常 `ex`；DO 在 `domain.entity`（**不是 `domain.do`**），DTO 分 `domain.dto.req` / `resp`。
6. **安全三层**：`@RequireRole` → Service 判数据归属 → 学生/教师身份一律从 `UserContextHolder` 取，不信任请求参数。

- **推送**：走代理 `GIT_TERMINAL_PROMPT=0 git -c http.proxy=http://127.0.0.1:7890 -c https.proxy=http://127.0.0.1:7890 push origin master`。坑：push 后 `.git/refs/remotes/origin/master` 写不进文件，`git branch -vv` 会显示 `[origin/master: gone]`，但**推送实际成功**（看 `.git/FETCH_HEAD`）；修复用 Python 直接写该文件（一行 40 位 sha）。

## 9. 常用命令

```bash
# 编译（离线；先备份冒烟脚本，clean 会清掉 target/*.py）
cp target/smoke.py target/smoke_admin.py target/smoke_selection.py /tmp/smokebak/
mvn -o -B compile -DskipTests

# 启动（必须显式指定端口）
mvn -B spring-boot:run "-Dspring-boot.run.arguments=--server.port=8080"

# 冒烟（应用启动后）
python target/smoke.py            # 学生端 + 教师端
python target/smoke_admin.py      # 管理端 + V2.0 新接口可达性
python target/smoke_selection.py  # 选课退课闭环

# 查看进度
git log --oneline -26
git status --short src/
```
