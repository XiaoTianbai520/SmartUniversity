# 高校智慧教务选课平台 V1.1 接口清单

## 1. 通用约定

| 项 | 说明 |
|---|---|
| 基础路径 | `/api/v1` |
| 鉴权 | JWT，未登录返回 `40101` |
| 权限 | 由 `@RequireRole` 控制，越权返回 `40301` |
| 请求体 | `application/json`，`@Valid` 校验 |
| 响应体 | `Result<T>`：`{ code, message, data, timestamp }` |
| 分页入参 | `page`（默认 1）、`pageSize`（默认 20） |
| 分页出参 | `PageResult<T>`：`{ records, page, pageSize, total }` |
| 时间格式 | `yyyy-MM-dd HH:mm:ss` |
| 空值策略 | `null` 字段不序列化 |

## 2. V1.1 新增错误码

| code | 说明 |
|---|---|
| 40918 | 当前不满足候补条件 |
| 40919 | 候补记录不存在 |
| 40920 | 已存在候补记录 |
| 40921 | 教学班仍有余量，请直接选课 |
| 40922 | 候补递补失败 |
| 40923 | 导入文件为空 |
| 40924 | 导入文件格式错误，仅支持 xlsx |
| 40925 | 导入文件解析失败 |
| 40926 | 导入数据为空 |
| 40927 | 导出数据为空 |
| 40928 | 通知不存在 |
| 40929 | 专业不存在 |
| 40930 | 年级不存在 |
| 40931 | 行政班级不存在 |
| 40932 | 成绩必须在 0 到 100 之间 |

# 3. 候补选课接口

## 3.1 加入候补

```http
POST /api/v1/student/teaching-classes/{teachingClassId}/waitlist
```

权限：`ROLE_STUDENT`

路径参数：`teachingClassId` 教学班 ID

请求体：无

响应：

```json
{
  "selectionId": 1001,
  "teachingClassId": 88,
  "teachingClassName": "2026秋季 Java程序设计 01班",
  "courseName": "Java程序设计",
  "teacherName": "张老师",
  "credit": 3.0,
  "status": "WAITING",
  "capacity": 60,
  "selectedCount": 60,
  "waitingCount": 7,
  "waitlistNo": 3,
  "waitlistRank": 3,
  "waitingAt": "2026-09-28 12:00:00"
}
```

> 加入候补与候补列表共用 `WaitlistRespDTO`，因此加入候补同样返回教学班与课程等展示字段。

失败场景：

| 场景 | code |
|---|---|
| 教学班不属于当前学期 | 40001 |
| 不在选课时间 / 教学班未在该批次开放 | 40912 |
| 专业不符合 | 40914 |
| 年级不符合 | 40915 |
| 已正式选中该教学班 | 40909 |
| 已在候补队列 | 40920 |
| 与已选课程时间冲突 | 40908 |
| 超过学分上限 | 40911 |
| 教学班仍有余量 | 40921 |

## 3.2 取消候补

```http
DELETE /api/v1/student/waitlist/{selectionId}
```

权限：`ROLE_STUDENT`

路径参数：`selectionId` 选课记录 ID

响应：`Void`

失败场景：记录不存在 `40919`；不是本人记录 `40919`；状态不是候补中 `40918`；批次已结束 `40912`。

## 3.3 查询我的候补列表

```http
GET /api/v1/student/waitlist
```

权限：`ROLE_STUDENT`

查询参数：`page`、`pageSize`（可选）

响应：`PageResult<WaitlistRespDTO>`

```json
{
  "records": [
    {
      "selectionId": 1001,
      "teachingClassId": 88,
      "teachingClassName": "2026秋季 Java程序设计 01班",
      "courseName": "Java程序设计",
      "credit": 3.0,
      "teacherName": "张老师",
      "capacity": 60,
      "selectedCount": 60,
      "waitingCount": 7,
      "waitlistNo": 3,
      "waitlistRank": 3,
      "status": "WAITING",
      "waitingAt": "2026-09-28 12:00:00"
    }
  ],
  "page": 1,
  "pageSize": 20,
  "total": 1
}
```

## 3.4 教务手动触发候补递补

```http
POST /api/v1/admin/teaching-classes/{teachingClassId}/waitlist/promote
```

权限：`ROLE_ADMIN`

响应：

```json
{
  "teachingClassId": 88,
  "promotedCount": 1,
  "invalidCount": 0,
  "promotedStudentNos": ["2026010101"]
}
```

说明：正常情况下退课与容量上调会自动递补，该接口用于教务人工干预和数据兜底。

# 4. 系统通知接口

## 4.1 分页查询我的通知

```http
GET /api/v1/notifications
```

权限：`ROLE_STUDENT` / `ROLE_TEACHER` / `ROLE_ADMIN`

查询参数：

| 参数 | 说明 |
|---|---|
| `page`、`pageSize` | 分页 |
| `noticeType` | 可选，按类型过滤 |
| `isRead` | 可选，0 未读 / 1 已读 |

响应：`PageResult<NotificationRespDTO>`

```json
{
  "records": [
    {
      "notificationId": 5001,
      "noticeType": "SCORE_PUBLISHED",
      "title": "成绩已发布",
      "content": "《Java程序设计》成绩已发布，请前往查看。",
      "bizId": 88,
      "isRead": 0,
      "createdAt": "2026-09-28 15:30:00"
    }
  ],
  "page": 1,
  "pageSize": 20,
  "total": 1
}
```

## 4.2 查询未读数量

```http
GET /api/v1/notifications/unread-count
```

响应：

```json
{ "unreadCount": 3 }
```

## 4.3 标记单条已读

```http
PUT /api/v1/notifications/{notificationId}/read
```

权限：任意登录角色，但只能操作本人的通知

响应：`Void`

失败场景：通知不存在或不属于当前用户 → `40928`

## 4.4 全部标记已读

```http
PUT /api/v1/notifications/read-all
```

响应：

```json
{ "updatedCount": 3 }
```

# 5. 批量导入导出接口

所有导入接口使用 `multipart/form-data`，字段名统一为 `file`；导出接口直接返回 xlsx 二进制流。

## 5.1 导入学生

```http
POST /api/v1/admin/students/import
Content-Type: multipart/form-data
```

权限：`ROLE_ADMIN`

模板列：学号、姓名、专业编号、年级名称、班级编号、初始密码（选填）

响应：

```json
{
  "totalCount": 50,
  "successCount": 48,
  "failCount": 2,
  "failList": [
    { "rowIndex": 12, "identifier": "2026010099", "reason": "专业编号不存在" },
    { "rowIndex": 31, "identifier": "2026010100", "reason": "学号已存在" }
  ]
}
```

> `rowIndex` 从数据第一行开始计数，跳过表头。

## 5.2 下载学生导入模板

```http
GET /api/v1/admin/students/import-template
```

返回：带表头的空模板 xlsx。

## 5.3 导出学生信息

```http
GET /api/v1/admin/students/export
```

权限：`ROLE_ADMIN`

查询参数：与现有学生分页查询一致（`keyword`、`majorId`、`gradeId`、`classId`、`status`）

导出列：学号、姓名、专业、年级、班级、学生状态、账号状态

失败场景：无匹配数据 → `40927`

## 5.4 导入教师

```http
POST /api/v1/admin/teachers/import
```

模板列：教师编号、姓名、职称（选填）、初始密码（选填）

响应格式同 5.1。

## 5.5 下载教师导入模板

```http
GET /api/v1/admin/teachers/import-template
```

## 5.6 导出教师信息

```http
GET /api/v1/admin/teachers/export
```

查询参数：`keyword`、`title`、`status`（可选）

导出列：教师编号、姓名、职称、状态、账号状态

## 5.7 导出教学班学生名单

```http
GET /api/v1/teacher/teaching-classes/{teachingClassId}/students/export
```

权限：`ROLE_TEACHER`

导出列：学号、姓名、专业、班级

失败场景：教学班不属于当前教师 → `40303`

## 5.8 下载成绩导入模板

```http
GET /api/v1/teacher/teaching-classes/{teachingClassId}/scores/import-template
```

说明：模板预置该教学班已选学生的学号与姓名，成绩列留空由教师填写。

## 5.9 导入成绩

```http
POST /api/v1/teacher/teaching-classes/{teachingClassId}/scores/import
Content-Type: multipart/form-data
```

权限：`ROLE_TEACHER`

模板列：学号、姓名、成绩

行校验规则：

| 规则 | 错误提示 |
|---|---|
| 学号不在本教学班或未处于已选状态 | 学生不属于该教学班 |
| 成绩为空或非数字 | 成绩格式错误 |
| 成绩不在 0 ~ 100 | `40932` |
| 成绩已发布 | `40916` |

响应格式同 5.1。

# 6. 教师成绩统计接口

## 6.1 查询教学班成绩统计

```http
GET /api/v1/teacher/teaching-classes/{teachingClassId}/score-statistics
```

权限：`ROLE_TEACHER`

路径参数：`teachingClassId` 教学班 ID

响应：

```json
{
  "teachingClassId": 88,
  "teachingClassName": "2026秋季 Java程序设计 01班",
  "courseName": "Java程序设计",
  "teacherName": "张老师",
  "selectedCount": 60,
  "scoredCount": 58,
  "unscoredCount": 2,
  "averageScore": 78.6,
  "maxScore": 99.0,
  "minScore": 42.5,
  "passRate": 89.7,
  "excellentRate": 25.9,
  "distribution": [
    { "range": "0-59",   "count": 6,  "rate": 10.3 },
    { "range": "60-69",  "count": 12, "rate": 20.7 },
    { "range": "70-79",  "count": 25, "rate": 43.1 },
    { "range": "80-89",  "count": 11, "rate": 19.0 },
    { "range": "90-100", "count": 4,  "rate": 6.9 }
  ]
}
```

字段口径：

| 字段 | 说明 |
|---|---|
| `selectedCount` | 该教学班正式选课人数 |
| `scoredCount` | 已录入成绩的人数 |
| `unscoredCount` | 未录入成绩的人数 |
| `averageScore` | 平均分，保留一位小数 |
| `passRate` | 及格率（>= 60），百分比保留一位小数 |
| `excellentRate` | 优秀率（>= 85），百分比保留一位小数 |
| `distribution` | 五段分布，各段人数与占比 |

无成绩时：`scoredCount` 为 0，`averageScore` / `maxScore` / `minScore` / `passRate` / `excellentRate` 均为 0，`distribution` 各段人数为 0。

失败场景：教学班不存在 `40405`；不属于当前教师 `40303`。
