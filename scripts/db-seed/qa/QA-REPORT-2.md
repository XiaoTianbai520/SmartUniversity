## 0.2 退课率口径（**已由 team-lead 拍板，后续复验一律沿用**）

```
退课率 = 退课数 / (SELECTED + WITHDRAWN)
```

- **理由**：分母代表"报名总量"，退课是其中撤单的部分；若用「退课 / 当前 SELECTED」，分母会随退课数量本身漂移，不适合跨学期对比。
- 本口径下：sem3 = 620/9559 = **6.49%**、sem4 = 780/11969 = **6.52%**，与工程师声称一致。
- 其余学期参考值：sem9 8.10%、sem10 7.59%、sem11 8.18%、sem12 8.26%、sem1 8.05%、sem2 8.37%、sem5 13.21%。
- ⚠️ 上一轮我同时报过「退课/当前 SELECTED」= 6.94%/6.97%，该口径**自本轮起废弃**，报告中如再出现即为笔误。
