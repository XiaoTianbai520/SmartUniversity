# 高校智慧教务选课平台 AI 开发说明

## 项目文档

AI 开始开发前，应优先阅读：

1. 高校智慧教务选课平台_需求文档.md
2. 高校智慧教务选课平台_版本开发规划.md

根据当前任务进一步阅读：

- 业务逻辑：
  高校智慧教务选课平台_V1业务流程设计.md

- 数据库：
  高校智慧教务选课平台_V1_ER图与数据库模型.md

- API（全量，含 V1.0 + V1.1）：
  接口清单.md

## 开发原则

1. 严格遵循需求文档定义的业务范围。
2. 当前只开发 V1 范围内功能。
3. 不擅自添加或修改业务规则。
4. 数据库设计以现有 SQL 和 ER 模型为准。
5. API 实现以接口文档为准。
6. 开发前先分析当前任务涉及哪些文档。
7. 如果文档之间存在冲突，先报告冲突，不要自行猜测。
